# Rineya Puzzle Reasoning 51K

## Summary

Rineya Puzzle Reasoning 51K is an original, procedurally generated English dataset for training and evaluating concise puzzle reasoning. It contains 51,000 examples across 15 symbolic reasoning families. Each row has a natural-language problem, solver-derived reasoning steps, a compact state, a canonical short answer, accepted variants, and a machine-readable structure that can be independently verified.

## Source and provenance

All rows were generated by the included code. No public benchmark rows were imported or paraphrased. The task-family design was conceptually informed by research directions represented by MindGames-style epistemic logic, Zebra-style constraint satisfaction, BIG-Bench-style diverse reasoning, ProofWriter-style rule deduction, and search-based planning benchmarks.

## Splits

- Train: 40,800
- Validation: 4,080
- Test: 4,080
- Challenge: 2,040

Language-template groups are disjoint across all four splits. Exact prompt and structured-instance deduplication is enforced globally.

## Intended uses

- Supervised fine-tuning for puzzle and logic reasoning.
- Reasoning-then-short-answer curricula.
- Final-answer compression or brevity preference tuning.
- Per-family diagnostic evaluation.
- Research on explicit reasoning traces versus compact answers.

## Out-of-scope conclusions

Accuracy on this dataset alone should not be described as general intelligence, human-level reasoning, or unrestricted real-world reliability. The tasks are controlled and synthetic.

## Verification

Every released row was independently re-solved by a family-specific checker after generation. The release validation report records 51,000 passing rows and zero duplicate prompts or structures.

## Personal and sensitive data

The dataset contains fictional short names and synthetic situations. It contains no collected personal data.
