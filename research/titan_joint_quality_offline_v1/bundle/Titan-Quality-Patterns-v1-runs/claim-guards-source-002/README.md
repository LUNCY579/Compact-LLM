# Titan quality research addons

These additive tools sit outside the active Titan and TAPS worktrees. They do not load, train, evaluate, select, release or serve native models. Existing campaigns and reviewed v1/v2 sources remain unchanged.

`claim_guards.py` reads only the existing, hash-bound open v2 PILOT when `load_open_pilot_fixture()` is called. Its loader compiles the exact verified source buffers in a temporary namespace, without writing caches. Prompts and references remain separate. The inspector separately hashes actual caller inputs; source/review pins do not attest arbitrary caller fixtures as reviewed data or native evidence. Native result import is refused.

The fixture inspector preserves the original analysis under `legacy_diagnostics`. It adds per-domain Sparse-correct, Supa-correct and Supa-correct/Sparse-wrong case and parent counts. Retention and recovery have separate source requirements. Empty recovery deficits remain null and unmeasurable; they cannot establish restoration. Minimum nonempty panels do not establish statistical adequacy.

Reasoning depth comes from the actual public queried dependency graph. Deep rows have depth at least two, and their accuracy is averaged within each eligible parent before averaging parents equally. An overall reasoning gain does not automatically establish a deeper reasoning gain. The positive deep-parent requirement is an explicit **proposed additional claim guard pending owner registration**. It changes neither the original five-point gain/two-point control margins nor historical stopping and selection rules. The owner must review and freeze any new rule before model outcomes.

Fixture pass flags are software checks. Actual release, native authority, winner and model-quality flags always remain false. Synthetic fixture pair proofs are not trained checkpoint or exposure evidence.

`pruning_controls.py` supplies bounded vector mechanics for dense, stable top-25-percent and per-tensor norm-matched uniform scaling controls. It refuses native checkpoints and raw LoRA factors. These controls remain a separate future comparison, applied once to a new child delta relative to its immediate Sparse parent. Per-tensor norm matching is different from a global interpolation coefficient.
