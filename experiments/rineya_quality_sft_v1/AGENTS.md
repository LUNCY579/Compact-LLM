Implement only this package on codex/rineya-quality-sft-v1. Other experiment
packages are read-only dependencies, not sources of grants or qualification.
Preserve source checkpoint bytes, DSD work, historical results and serving policy.

Read PROTOCOL.md and README.md. Existing dataset-quality owner alone constructs
and admits the requested fresh bank. Never generate a competing real bank, admit
TEST_ONLY/EXCLUDED derivatives, read protected banks, or invent owner/reviewer
approval. Tiny synthetic fixtures are implementation evidence only.

Use exact ungated Supa 1.7. No downloads, remote code, paid services, cloud jobs,
precision fallback, resource-floor reduction, silent truncation, missing-row
exclusion, extra response-arm examples, automatic retries or training grids.
All outputs/caches/environments live under BusinessProject outside Git checkouts
and .codex. Native runs require actual bank admission, matching qualification,
explicit execution flags, serial ownership and durable failures/checkpoints.

Full histories remain intact. Response targets cover the FINAL assistant answer
plus EOS; prior assistant history remains input only for that objective. Whole
targets cover all next-token positions. Complete parent/pair groups stay intact.
Quality dimensions, source-correct damage/repair, strict format and semantic
adjudication remain separate. Missing ratings/adjudications block advancement.
