# Scope and evidence boundaries

Work only on this dedicated RSR experiment unless the user explicitly expands scope.
Preserve the pinned parent and inherited RHD files; no force-push, merge to main,
production modification, unrelated project change, or PR creation is implied.
Do not start Codex tasks, automation jobs, model downloads, paid calls or GPU runs.
Native model calls and training require fresh host-specific authorization.

Run the complete scoped tests after changes. If any executable root Python file or
pinned upstream module changes, old run bundles require recollection/requalification.
Keep private runbooks, reviewer notes, source catalogs, actual logs and rejected
proposals out of Git. Never change a fixture's label to native evidence. No model
promotion or retention-positive claim can follow from this package's CPU test pass.

A native extension must preserve complete attempt denominators, source ancestry,
privilege separation, exact public-prefix SFT masks, fresh execution and paired
H0-only evaluation. Do not weaken a gate merely to make an imported run pass.
