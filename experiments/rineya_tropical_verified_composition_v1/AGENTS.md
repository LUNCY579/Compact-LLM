# TRVC-001 local experiment rules

Keep this work isolated. Do not merge to main, alter existing experiments, invoke
Codex tasks, start schedules, access other game projects, download models, spend
money, or start a job on TheFakeGod based on these files alone.

CPU reference work is allowed. Native execution requires checkpoint/tokenizer/code/
data identities, actual resource and mask/parity/backward/resume evidence, and a
reviewed source-bound execution envelope. Static declarations are not receipts.
Never weaken a preflight simply to obtain a PASS.

Do not treat archive retention as neural retention; report model-only, archive-
assisted and distilled performance separately. Do not describe finite-bank
log-sum-exp training as on-policy MaxRL. Do not train on evaluation or guard rows,
construction witnesses, or privileged future-state fields. Preserve failed attempts
and costs. Never relabel successful restart suffixes as wholly failed root traces.

Exact task/state/depth equality is required for joins. No embedding-similarity
joins, approximate state hashes, implicit extra horizon, unobserved edges or silent
memory eviction. Rescore under one declared frozen policy before composition.
Keep collected candidate identity separate from current-policy probability.

Run the scoped suite and CPU fixtures after changes; save new receipts rather than
overwriting published evidence. Existing native prerequisite gaps must be stated,
not hidden behind test counts. A dedicated branch is not an efficacy result.
