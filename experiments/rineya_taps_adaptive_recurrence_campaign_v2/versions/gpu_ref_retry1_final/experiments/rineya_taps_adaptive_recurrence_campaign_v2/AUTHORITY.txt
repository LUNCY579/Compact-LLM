8. MATHEMATICAL CONTRACT FOR THE CONTROLLER

Use explicit indexing and distinguish observations from extra block applications. Let h_k be the state entering the observed frozen block, F(h_k; u) its proposal with unchanged allowed conditioning, and d_k = F(h_k; u) - h_k its RAW update. The controlled extra application is:

h_(k+1) = h_k + alpha_k d_k.

The current package tracks bias-corrected moments, per sequence:
m_t = beta m_(t-1) + (1-beta) d_t
v_t = beta v_(t-1) + (1-beta) mean(d_t^2)
M_t = m_t / (1-beta^t)
V_t = v_t / (1-beta^t)
P_hat_t = mean(M_t^2)
S_hat_t = max(V_t - P_hat_t, 0)
B_t = (P_hat_t - gamma S_hat_t) / (P_hat_t + gamma S_hat_t + eps)
alpha_t = clip(1 + rho B_t, alpha_min, alpha_max).

The v1 reference uses beta=.8, gamma=1.5, rho=.275, bounds [.8,1.2], one warmup observation, eps=1e-12, refresh interval one, and fixed grid {.8,.9,1,1.1,1.2}. Verify exact semantics in code. Do not call these settings optimal for Rineya.

Requirements:
- FP32 moment arithmetic, finite checks, explicit masks and normalization denominator, and per-sequence reductions with no cross-batch contamination.
- Moments consume raw proposed updates, not previously scaled movements.
- The ordinary first pass is unchanged and seeds the WHOLE L12-L13 block update from the first layer's entry to the last layer's proposal.
- Return the actual proposal through the exact unit-scale path; do not lose identity through cancellation arithmetic.
- Reset at each independent sample and each full-prefix model call according to v1's contract. Cross-prefix carry is a new intervention, not a free optimization.
- Native last-token generation receives only information available in the current input prefix. Sequence-wide statistics can break earlier-logit prefix invariance even when final next-token generation is valid; do not claim all-position causal parity.
- Observed energies are proxies, not signed task progress or guaranteed movement toward a correct answer.

Derive and test the moment/variance identities, limiting/zero-update behavior, scale bounds, warmup, mask behavior, and reset semantics.
