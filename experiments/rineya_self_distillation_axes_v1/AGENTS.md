# DSD-001 contributor rules

Work only in this subtree on its dedicated branch. Preserve the parent, existing
source checkpoints, experiment evidence and all unrelated projects. Never push to
main/post-training-Mimo, force-push, merge another research branch, or change a
production default as part of this experiment.

Read README, PROTOCOL, SOURCE_MAP and VERIFICATION. Keep controlled mechanics,
tiny-fixture tests, exact-checkpoint qualification, native execution and behavioral
efficacy distinct. A completed plan is not a trained model. No claim of preventing
forgetting or reproducing paper-wide results is authorized by CPU mechanics.

Do not remove teacher detachment, same-response causal alignment, separate KL/EMA
controls, frozen-state hashes, no-live-graph swap guards, independent data admission,
identity checks, complete evaluation coverage or create-only failure receipts.

No automatic downloads, remote code, sealed/spent-bank reads, relabeled admission,
cloud spending, unattended sweeps, source checkpoint edits or trained-weight commits.
Only fresh synthetic controlled evidence belongs in source control. Native training
requires matching qualification and explicit --execute-training. Any new precision,
rehearsal/composition, teacher template, evaluator or optimizer variant needs its own
prospective design, not retrospective edits to a favorable outcome.
