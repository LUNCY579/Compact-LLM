# RDD-001 contributor boundaries

Work only in this experiment directory on its dedicated branch. Do not change
other research, production inference, protected evaluation banks, model files,
CI schedules, or laptop automations. Do not force-push or merge without approval.

Keep rollout source, KL direction and learning rate independent. Preserve public
teacher/student prompts, frozen teacher, full-vocabulary normalization, current
student version checks, sequence-mean reduction, independent fixed replay,
reference-fixed retention, complete paired seeds and unopened confirmation.
Do not turn unsuccessful/capped attempts into silent filtering.

Passing CPU tests is mechanical evidence only. Native execution requires the
existing E0 and export-parity evidence, a currently available/approved host,
explicit model/training permissions, resource admission, a shared GPU lock and
new runtime qualification. Never lower a guard or fabricate a receipt to proceed.
Do not substitute stock Qwen, a random model, a smaller student, quantized teacher
or API output. Keep fixture labels visible; 344M is not this campaign's target.

Test with `python -m pytest experiments/rineya_distillation_dynamics_v1/tests -q`.
Use new output directories. A failed run/confirmation remains failed/spent.
Update PROTOCOL/RUNBOOK and tests with any semantic change before a new native
registration. Explicitly distinguish implemented, mechanically tested, native
qualified, and efficacy demonstrated. Preserve complementary prior discoveries.
