## The one-line answer to the question the protocol asked

*Can additional interventions improve acquisition or useful reasoning beyond the existing static
delta, while preserving measured existing capabilities, and at what actual cost?*

**On acquisition, the only intervention that measurably beats the static delta is a bigger base
model** — 270 against 232, for 142 seconds of training, on legitimately held-out parents. **Every
weight-space intervention on the existing delta is the same intervention wearing different
clothes:** mask, truncate or scale it, and what you get is a function of the resulting magnitude
alone, which this screen establishes by building the control that separates them. **Nothing
preserves existing capability** in the strict sense — every arm loses source answers and every
arm damages abstention, the latter now **confirmed rather than observed** on a sealed instrument, and accompanied by a larger role-binding regression that no arm comparison had separated. And the **actual** cost of a compressed skill is not 27.7 MB: the
deployable artifact is 2.38 GB, the same as everything else, because no factored serving path
exists.

The multi-reasoning half of the question has no answer here, and the reason is stated rather
than hidden: it needs a bank whose floor has been checked, and building one was outside what
this stage could execute without spending calls on an uninterpretable instrument.
