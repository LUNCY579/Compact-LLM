# Scoped maintenance rules

Preserve the isolated RHF-001 experiment and pinned base. No model/checkpoint,
benchmark, game, main-branch, or sibling-experiment writes. Do not execute native
runs, schedule tasks, install packages, or incur cloud charges by default.
Keep source and evidence separate. Numeric errors must remain blocked; never
weaken a gate to make a receipt pass. Record deviations from the paper and
upstream code explicitly. Do not claim native or broad-retention efficacy from
synthetic, captured-activation-only, or mock-model tests. Use new output paths.
Run this package's entire test suite after changes; preserve source hashes and
negative outcomes. No executable code or pickled objects in serialized artifacts.
