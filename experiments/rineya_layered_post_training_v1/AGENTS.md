# RLP-001 working rules

Keep changes inside this experiment unless the user separately authorizes integration.
Do not launch Codex tasks, background jobs, GPU training, downloads, or paid APIs on
behalf of another workflow. CLI native training requires explicit load/training flags.
Do not change main, post-training-Mimo, Flip Hero, or the user's game projects.

Synthetic GRU tests establish mechanics only. Never report them as Rineya/Qwen3 gains.
Never fit coefficients, preferences, critics, or stopping rules on confirmation scores.
Do not lower retention floors, sample counts or likelihood tolerances after inspecting
confirmation. Use a fresh preregistered cohort to change the experiment.

Reuse the pinned PRLC objective; do not edit its public semantics. Never average LoRA
A/B factors and call the result a weighted sum of effective updates. Preserve all
checkpoint parents, coefficients, data fingerprints and negative results. Do not
merge optimizer moments across soup boundaries. Run the scoped tests before publishing.
