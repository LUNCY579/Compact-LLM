# Cached arithmetic gain/loss stability

Study 1 of the authorized cheap Rineya quality programme. This CPU-only study
re-scores the 150 exposed monitor items in four retained B28last20 WSD draws.
It identifies recurring acquisitions and recurring damage to source successes,
preserving both strict and permissive unit policies. It loads no weights and
imports no model framework.

Read [PROTOCOL.md](PROTOCOL.md) and the frozen [config.json](config.json) first.
Run only through the programme's hardware supervisor, one study at a time, with
512 MiB process-tree RSS, 900 seconds, and 50 MiB output limits. The script also
checks elapsed time and total output size; external supervision supplies measured
memory, host RAM, CPU and GPU observations and termination on a resource breach.

From this worktree's repository root, the supervised child command is:

```powershell
python -B experiments/cheap_quality_stability_v1/analyze.py --output experiments/cheap_quality_stability_v1/runs/stability-20260929-001
```

Use the supervisor's selected Python executable in place of `python`. A run
directory must be new; the script never replaces an existing result. The actual
executable, version, platform, source identities, scoring policy, configuration
and exact input/implementation hashes are saved in `freeze.json` before scoring.
On invalid input it preserves `failure.json`, exits nonzero, and emits no success
summary. A successful run creates `summary.json`, `items.json`, `items.csv`,
`pairwise.csv`, `family.csv`, and a readable `report.html`; its integrity status
means cached evidence reproduced, not model qualification or a retention pass.

Tiny synthetic mechanics tests (no cached analysis, weights or model imports):

```powershell
python -B -m unittest discover -s experiments/cheap_quality_stability_v1/tests -v
```

Historical inputs and their PASS/FAIL labels remain immutable. The inherited
architecture benchmark, native admission floors and all stages remain unchanged.
There is no causal WSD effect, fresh evaluation, release, training authorization,
or pooled independent-observation claim in this study.
