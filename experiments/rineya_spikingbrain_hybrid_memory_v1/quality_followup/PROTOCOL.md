selection. The intervention changes both order diversity and position frequencies;
it does not separately identify those mechanisms. No memory-architecture conclusion
or recurrence benefit can follow from this comparison.

## Data and metrics

New data is synthetic and unprotected TRAIN/DEV only. There are no sealed,
confirmation, CHECK, FINAL or promotion instruments. Independent raw-prompt
oracles reject ties, missing fields, incorrect targets and changed counterfactual
truths. Tokenizer replay must confirm every frozen geometry and exposure hash.
Resampling is confined to structural/semantic validity (including distinct update
values) and token/shape invariants before freezing, never based on model correctness
or after inspection of native outputs.

Strict exact match preserves the historical string rule. Typed correctness requires
the complete expected JSON key/type contract and case-sensitive correct values.
Duplicate keys, nonfinite JSON, malformed text and extra/missing fields fail.
Contract compliance is separate from value correctness. Formatting-only repairs
cannot be silently reclassified as acquired reasoning ability.

Retain world/counterfactual/evidence-position/permutation identity. Six-order
correctness requires all six correct; mere consistency, including always-null or
always-wrong behavior, cannot pass. The 16 DEV update worlds are dependent units.
The primary 26/256 net-correct threshold is a prospective engineering review gate,
not a confidence interval, significance claim or model-selection campaign.

Apply baseline sufficiency (>=16 correct cases in >=4 skills) and zero candidate
damage separately to strict and typed-value retention. Never pool their source-
correct denominators or subtract repairs from damage. Report both absolute
answerability cells; no-worse-than-control alone does not establish calibration.

## Native receipts and stop rules

Each receipt binds the study, condition, full implementation code, source,
tokenizer, config, frozen corpus, exposure ledger, environment and exact delta.
Training exports actual input/label hashes at each runtime slot, finite loss and
gradient checks, explicit trainable names/counts and unchanged optimizer settings.
DEV records raw predictions, generated IDs, stops, cache geometry and instrumented
resources. Native qualification remains inference mechanics, not broad quality.

A new exact native permit and fresh ownership checks are mandatory. Imported
historical permissions, stale qualification, another source/condition, modified
data/code, missing controls, changed exposure or reused outputs stop execution.
All historical source files, modifications, corpora and native receipts are
preserved. Model publication, serving changes and subsequent studies require
separate decisions; this protocol authorizes none.
