# SBHM-001 experiment scope

Only modify this experiment directory for SBHM-001 unless the owner separately
approves integration. Do not modify other research, application/game code,
checkpoints, source branches, main, protected datasets, or historical receipts.
Never force-push, merge, archive, or retire another track for this experiment.

Read README.md, PROTOCOL.md, STATUS.md, and SOURCES.md before continuing.
Implementation approval is not approval to run pretrained-model training.
Native commands require exact source manifests, fresh resource checks, dated
operator grants, and variant-bound qualification. Do not lower guards to fit.
No download, pretrained checkpoint, GPU execution, or protected data is needed
for the offline tests. Fixtures and skipped integration tests are not evidence
of native Rineya capability. The native runner supports ONLY standard, ungated,
HF-format Qwen3; unsupported Rineya loaders must not silently substitute Qwen.

Do not infer head dimension from hidden width. Retain GQA, QK normalization,
source identity and tokenizer contracts. Converted sites must remove their
full-history KV cache. A one-site pilot does not give constant total-model
memory. The sequential reference is not a performance-optimized kernel.

SBHM complements retention, skill composition, TAPS/depth recurrence, and the
centralized reasoning system. Negative results should reject a hypothesis or
configuration, not erase existing research. No promotion from fixture losses,
activation sparsity, paired development counts, or one seed. No native launch,
source upload, evaluation-bank access, or external service spend is authorized
by this file or by the checked-in example configuration.
