JSON objects with string code values. Strict and typed update correctness are
therefore zero; 198/384 match the expected code digits only under the explicitly
type-erasing diagnostic. Do not call those typed or semantic model successes.

Latest-code digit matches by latest-record placement: first 33/128, middle
105/128, last 60/128. Middle beats first in every one of 16 worlds. Only eight
of 64 bundles match the correct code across all six orders. The ten order-
consistent bundles all match the greatest code value; two are consistently
wrong. In 192 rows where greatest code and greatest revision disagree, the
source matches greatest code 85 times and correct latest code 66 times.
43 outputs match visible revision numerals instead of code payloads; 41 are
on distant rows. These are output associations, not identified internal algorithms.

A fixed target-blind, type-preserving scalar JSON wrapper hypothetically changes
saved-output strict/typed correctness from 55/672 to 123/672, preserving all
existing correct cases. It repairs 41 general and 27 present-evidence cases,
zero update and zero retention cases. It changes no model and supplies no
intrinsic-quality gain. Wrapper, scalar type and selected-payload changes must
be reported with joint flags; they are not disjoint causal explanations.

for every absent case. The field-agnostic rule count>=2 predicts presence on
