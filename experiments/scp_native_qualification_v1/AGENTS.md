historical branches, files, grants, source locks, catalogs, checkpoints and evidence.
Work only on a new dedicated successor unless the user explicitly directs otherwise.

Do not remove either native refusal to make tests/status green. Scripted fixtures,
headers, request-shaped JSON and supplied resource snapshots do not qualify a native
host. Never attach a real backend through native=False or relabel fixture evidence.
Complete and review the exact-subject transport, unchanged MQ supervisor/RRP journal
attachment, qualified native observer and native receipt verifier before any launch.
Then obtain a separate exact-host one-launch inference approval. Never set a training
permission to satisfy an inherited grant validator. No training/confirmation opens.

Use external create-only records, preserve failures, no automatic retries, no source
or budget relaxation, no protected-bank reads, cloud or teacher jobs. Run scoped tests;
report their exact scope separately from parent tests, native checks and CI. Verify
remote branch head AND changed-file blob identities before claiming publication.
