# Research boundary

Work only in this isolated package/new authorized branch. Preserve all existing
branches, original evidence and active registered protocols. No main merge,
force-push, receipt replacement, sealed data access, native model execution,
training, weight download, or live controller deployment.

Read PROTOCOL.md before changing semantics. Synthetic tests are not historical
or native efficacy. Admit only source-bound, closed, context-valid histories;
never reconstruct scientific parentage from Git ancestry or result-table order.
Do not loosen gates to make an input pass. Use exclusive output directories.
After a source/protocol change, re-freeze before evaluation and retire any exposed
holdout. Include actual test output, source hashes, and honest NOT_RUN statuses.
