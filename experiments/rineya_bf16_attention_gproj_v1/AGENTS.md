Keep changes under this subtree and on its dedicated research branch. Do not merge
or push to main/post-training-Mimo, force-push, change production defaults, or touch
unrelated Rineya, game or workspace work. Preserve the parent and existing evidence.

Read README.md, PROTOCOL.md, SOURCE_NOTES.md and VERIFICATION.md. Separate synthetic
mechanics, exact-checkpoint qualification, native execution and efficacy. Never
claim this dense implementation is FlashAttention or that it reproduces fused cost.

relabel data admission, launch cloud jobs, install packages into a production
environment, or start training on the strength of CPU tests. Native training needs
an exact matching passing qualification and explicit --execute-training.

Do not remove actual-mass normalization, either gradient correction, shared-forward
controls, zero-reference metrics, explicit dispatch, FP32 masters, frozen-parameter
checks, config/source hashes, or output nonoverwrite guards. No tensor capture,
checkpoint, dataset, optimizer state or trained delta belongs in a source commit.
Retain failed evidence. Any gate change must be prospective and requalified.
