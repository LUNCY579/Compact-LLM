## What was tested

Six primary defect strata each contain four parents: unsupported decision,
missed exception, invalid output format, unwarranted answer to an underdetermined
query, wrong source citation and an observable forbidden private-key canary.
These categories can overlap. The canary tests a visible output/schema violation;
it does not prove that a reviewer observed actual private data access.

Public problems use four small Boolean/weighted policy layouts with an urgent
override and possibly unrecorded facts. Query answerability is independently
enumerated. Unknown inputs can still yield a determinate decision, especially
under an override; missing facts alone do not justify UNKNOWN. Citation sets are
explicit output instructions, not claims of minimal necessary evidence. JSON
whitespace/key order and citation order are accepted semantically.

The producer reserves all24slots and EXCLUDED ancestry before constructing or
solving worlds. All attempts, source examples, unit fixtures, target variants and
available semantic/public hashes enter exclusion records. Every clean/fault pair
passed a separate public-input oracle with its intended defect witness. All24
normalized bounded worlds are distinct; only four layouts are represented.

## Improvements made before execution

Independent review found and closed real source weaknesses: a predictable
operator-to-clean/fault assignment pattern, unverified oracle import, insufficient
class-specific fault witnesses, missing failed-world exclusions, substituted
candidate delivery paths/maps, mutable reviewer access scope/public hashes and
missing DEV exclusions. Controller tests reject these faults and preserve wrong
or personally uncertain public commitments as diagnostic observations without
gold-feedback retries.

The scorer also received changes-required review. It now derives labels from
public-oracle validity, joins exact candidate/parent/class identities, validates
the complete four-context opposite-view lattice, and retains malformed/missing
receipts in all96fixed denominators. Uncertain, missing, malformed and declared
exposure-invalid outcomes remain distinct. An all-uncertain judge cannot appear
reliable through zero accepted errors: its decisive coverage is zero and its
conservative unresolved error bound is one.

## Limits and retained failures

This result supports sensitivity on the executed finite grammar. It does not
establish production language grading, long-context prose coverage, human review,
independent-provider agreement or student intelligence gains. The96observations
come from24parents/48views and a shared model family; they are correlated. Zero
errors with four flawed parents per class gives little evidence about unseen
defects. Conservative missing-data bounds are not statistical confidence bounds.

Reviewers sometimes used their own public-only programs. Receipts state methods
and limitations; this is not a claim of unaided human reading. Declared path logs,
actual delivery order and local hashes provide procedural evidence. The shared
filesystem did not enforce cryptographic blindness or authenticated actor identity.

Several dispatch attempts hit the platform's thread limit and were serialized.
One reviewer initially attempted a root-specified wrong assignment filename;
the correction supplied the proper file in its permitted folder, with no gold.
Adversarial-B first hit provider capacity, then retried the same inherited model
and context before committing. No model downgrade, replacement parent, omitted
vote or feedback correction was used. All events are retained.
