must retain the queried alias/identity relations, applicable binding/condition/
fact/cancellation connectivity and actual query-relative chronology needed by
the registered semantics. Remove only demonstrably irrelevant components, such

ignored filler, source instructions or unqueried components cannot manufacture

alias direction, target references, actual premise states/modalities and rule

semantics are invariant: order/ties and query/binding/cancellation boundary

bounded typed graph or equivalent restricted term exactly. Do not use a heuristic
hash as graph equality, unbounded permutation search, or first source occurrence
as canonical name order. Impose explicit node/search limits and fail unavailable
when uniqueness/completeness cannot be verified.

Match each candidate against optimizer canonical roots and within-panel roots,
using both fingerprints. A full-world difference with an equal relevant cone is
not enough. Thirty-two deterministic rename controls should preserve the same
canonical identity and semantic answer while related-root admission rejects.

can have a different fingerprint. Counterfactual descendants need preserved root

an unrestricted counterfactual closure could contain every world. Declare what
transformations/ancestry the claim covers. Unknown provenance or unresolved
canonicalization remains unavailable, not presumed independent. Fresh deterministic
sampling and root counts do not establish statistical or natural-language independence.
