“capture before decision” ordering explicitly: a predeclared/proposed decision
must not masquerade as an applied decision, and any later decision must remain
immutably associated with the captured event. No application-body release occurs
on incomplete write/fsync/acknowledgement or logging failure.

Suppress only enumerated instrument-internal tracing; record the suppression and
cost limits rather than claim framework coverage across it. Inspect only builtin
scalar type/count and trusted frame/code metadata; no arbitrary repr/property/
iteration or argument-value dump. Thread-local entry/return identity and parent
association must survive concurrent events and refusal. C arguments stay UNKNOWN
when the API cannot observe them; a type label cannot satisfy a value-dependent

disable supervisor termination or become permission to continue the import.
