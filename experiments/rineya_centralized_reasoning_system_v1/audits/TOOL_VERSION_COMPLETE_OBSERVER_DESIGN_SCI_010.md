## A1: immutable receipt conflict is real, conditional on cost classification

The pinned library records a `native_outcome_observation` containing its measured native_started/native_end interval. `operations.write_receipt` fixes the filename from kind/key and rejects different existing bytes. `verify_receipt` requires that canonical filename/kind/key, and `reconcile` requires `actual_native_seconds == payload.elapsed_native_seconds`. The design therefore correctly identifies a conflict if an observer tries to overwrite/substitute that same immutable receipt with a larger aggregate of caller/observer activity. A new filename is not a valid replacement, and no hidden accounting adapter or extra reservation is authorized.

However, the receipt's narrower native interval is not inherently an undercharge of every activity. Actual native dispatch/qualified worker/verified exit time, caller preparation, observer validation/publication CPU bookkeeping, source/fixture engineering and overall wall are distinct quantities. Existing qualification/failure work must still be measured and charged against its **applicable** prospective budgets; none may silently disappear, be assigned zero, be clipped or gain a free baseline exclusion. Overlapping intervals must not be counted twice. The frozen design elects to classify the whole t0-through-observer-finalization governed wall as this same native field. That is a stronger aggregation premise, not evidence that the only valid full measurement is a single enlarged native interval.

Minimal clarification must state the canonical job subject, exact native start/end and which additional measured qualification/observer costs belong in which admitted cost/evidence fields or budget, including failure/overrun/unknown handling. If the fixed registration truly requires the enlarged aggregate in that one already-written native receipt, A1 remains a genuine unresolved pinned-interface blocker. If separately reported/charged bookkeeping is permitted, do not call the truthful native receipt a shortened charge merely because its value differs from complete caller/observer wall.
