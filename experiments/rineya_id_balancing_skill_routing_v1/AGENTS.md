# Scope: IDR-001 only

Keep changes inside this experiment unless the operator explicitly approves integration.
Never edit registered RCWM/BWM artifacts or another research branch. No main merge,
force-push, automatic PR, release, checkpoint publication, or task scheduling.

Paper-reference behavior and Rineya extensions must remain distinguishable. Do not
use gold outcomes, desired rewards, future tokens, or sealed labels as router inputs.
A proposer and forward world model are different operations, not interchangeable experts.

Keep the base and registered adapters frozen/unmerged in FP32. Do not silently
quantize, replace a native loader, fall back to synthetic data, or report CPU
mechanics as native efficacy. Missing native inputs must stop native execution.

Controller biases are selection-only, separate from composition strengths. Update
only after completed optimizer/calibration windows, never within generation/evaluation.
Protect per-family and per-stratum quality, not just uniform utilization. Diagnosis
must distinguish missing competence from missed expert selection.

Run scoped tests and the CPU matrix after changes. Preserve write-once outputs,
checkpoint identity, split custody, and consumed confirmation freezes. A failed
confirmation claim stays consumed; document an amendment rather than deleting it.
