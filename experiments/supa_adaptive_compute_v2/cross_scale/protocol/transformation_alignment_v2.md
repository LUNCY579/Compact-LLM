# Track B preregistration: frozen 4B transformation alignment

Scientific question: can the actual transformation of one frozen Qwen3-4B layer be faithfully recovered from Supa's residual stream? This stage has no generation and cannot establish capability. The historical post-Supa-L12 / donor-L16 ridge result remains unchanged: held-out delta cosine 0.443202525, global relative MSE 3.657591105, and 16/16 identical efficacy outputs.

The executable configuration is `configs/alignment_v2.json`. Its source, prompt-bank manifest, scorer, and registration must be committed before any real-model run. CPU float32, eager attention, four threads, deterministic algorithms, no cache; other runtimes require separate qualification. The programme-wide machine lease prevents competing Track A/B model processes.

All indices are zero-based. Capture raw Supa post-layer states at 8, 12, 16, 19 and native donor pre/post states for layers 12, 16, 20, 24. The full 4x4 matrix compares six objectives per pair, 96 cells. Every pair uses the same calibration prompts and scenario-held-out partition frozen by the Track B data manifest. Its 128 calibration scenarios are split 96 fit / 32 holdout; paired variants stay with their scenario. Track A data, architecture-development answers and confirmatory answers cannot enter fitting. The bridge-facing interface exposes only prompt and identity fields.

Capture uses the historical actual-Hugging-Face decoder and streamed official checkpoint tensors. Before extracting the calibration matrix, all four Supa capture sites must exactly equal direct canonical `Qwen3AbstainForCausalLM` raw-layer hooks on one fixture. Both token vocabularies and each rendered token sequence must match. Prompts exceeding the frozen 256-token limit fail before capture; truncation is forbidden so the final-prompt metric always refers to the original final token. Full and retained lengths are recorded and must agree. Special/control tokens are exactly the union of tokenizer special IDs and added-vocabulary IDs; ordinary tokens are the complement. Each metric separately reports all, ordinary, special/control, and final-prompt tokens. Empty special strata are reported as empty, never fabricated.

For Supa state h, z=RMSNormalize(h) U+b; native donor input y has target delta D=L(y)-y; predicted delta is L(z)-z. The output operator is h+g[(L(z)-z)V]. The affine downward bias cancels and never enters the residual. The donor receives the complete retained prompt, original positions and a causal mask; independent token forward passes are forbidden.

| Objective | Upward and downward fit |
|---|---|
| B0 | Historical affine ridge, relative penalty 0.01; RMS-normalized Supa upward input, raw donor downward input. |
| B1 | Same maps with inverse target-token mean-square weights (floor 1e-8), normalized to mean weight one. Weighted centering and weighted Gram determine the ridge penalty. This minimizes token-relative state error without high-norm tokens dominating. |
| B2 | Initialize B0; optimize up-map and bias through the actual frozen donor. Downward ridge map remains fixed. |
| B3 | Initialize B1; same optimization with per-token normalized losses. |
| BS | Historical ridge on a seeded permutation of all training target rows; every paired source and target belongs to a different scenario. Both maps use the same shuffled correspondence. Held-out targets are never shuffled or fitted. |
| BR | Historical seeded Gaussian bridge, with marginal training-RMS scaling; no paired fitting. |

B2/B3 train only U and b for exactly 96 Adam steps, learning rate 1e-4, gradient clipping 1.0, no validation early stopping or best-step selection. Seed 1702 defines a single shuffled order of training prompts; steps cycle that order. Each step uses one full prompt. Loss is delta relative MSE +0.10 mean(1-cosine(delta,D))+0.05 state relative MSE. B2 uses a global token-energy denominator within each prompt; B3 averages each token's error divided by its own target energy. Equal prompt frequency is intentional. Downward maps are fixed because this experiment tests donor input transformation fidelity; no target efficacy delta is available to supervise downward transformations. No Transformer weight or gate is trained. Frozen donor state hashes, trainable inventories and zero backbone gradients are checked before/after. All NaN/Inf or RSS budget violations are hard failures with receipts.

Primary selection metrics are held-out **ordinary-token** mean delta cosine and mean token-relative delta MSE. A B1/B2/B3 candidate must simultaneously achieve cosine >=0.60, improve over same-pair B0 by >=0.10, reduce token-relative MSE to <=0.80 of B0, exceed each same-pair BS/BR delta cosine by >=0.10, have all-token delta cosine >=0.50, and predicted/native ordinary-token delta RMS ratio in [0.25,4.0]. Selection requires all 16 pairs and all six objectives per pair. Null controls remain even when they win. Rank eligible candidates by descending ordinary delta cosine, ascending token-relative MSE, ascending Supa layer, ascending donor layer, lexical objective; freeze at most one candidate. These thresholds are chosen prospectively as a material fidelity improvement over the historical mechanism, not a capability threshold.

Also report up/down cosine and token-relative MSE, donor-delta global MSE, residual magnitude ratio, mapped-delta/Supa RMS, and fit-step traces. No metric is silently substituted after results. Selection data are exploratory engineering data; only a subsequent independent generation bank can test usefulness.

Each capture/pair/aggregate has immutable started/final manifests and failure receipts. Dense tensors live under ignored Track B `local/`, referenced by SHA256. Capture records source maps before/after; reuse requires the same registered source, config, all calibration IDs/partitions, checkpoint identities and activation hashes. Donor extraction checks the actual decoder layer index; fitting replays one fit and one held-out native donor transformation exactly before training. Backbone and rotary-embedding parameters remain frozen and gradient-free.

Before capture or pair loading, require at least 3 GiB available physical memory; process RSS must remain within 6 GiB. Canonical fixture forwards, individual donor forwards, held-out prompt evaluations and complete optimizer steps have a 900-second elapsed budget. Each complete capture and each pair has a 172800-second (48-hour) outer budget. Checks run between operations; forwards/backwards are not forcibly interrupted. The preserved streaming capture exposes per-layer callbacks, so its outer deadline is checked after each complete layer and at completion, while RSS is checked per prompt by the reused helper. Donor output/input global RMS must remain in [0.05,10]; the tighter delta-scale selection gate is separately specified above. Nonfinite values, elapsed deadlines or resource violations fail the attempt.

Pair attempts are independent directories: retries use a new attempt number, preserve failed evidence, and aggregation requires exactly one completed attempt per pair plus no unfinished attempts. If a worker exits without a final receipt, the explicit `abandon-pair` recovery command may write an additional abandonment receipt only after verifying its original PID is absent. It never deletes or rewrites partial evidence and refuses a live or uncertain worker. Aggregation hashes failed/abandoned attempts as well as successful attempts. Attempts with changed source/config/data require a new registration and run ID.

That stage must reject inert/destructive behavior and freeze a dose before confirmatory generation. It is not implemented or executed by this caller. The large 1,024-example efficacy bank remains closed to Track B until those gates pass. Required later arms are X0, frozen native XN when available, XG, XS, XR and XM. Paired shared statistics and baseline completeness checks apply then.

8B, routing, MLA/MHA/MTP, backbone recovery and distillation are closed. Exactly one next causal experiment: execute this frozen calibration-only 16-pair, six-objective matrix and determine whether delta-aware input alignment beats absolute ridge and both null controls on unseen scenarios.
