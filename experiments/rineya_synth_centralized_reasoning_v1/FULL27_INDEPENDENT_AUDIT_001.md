# Independent full27 chunk auditing

`auditor.py` verifies one complete terminal qualification chunk. It launches no
worker and grants no study training, warmstart or grading permission. No new
native full27 result exists. Before reading outputs/assets or writing a result,
the caller must supply `ROOT_TERMINAL_AND_PRESERVED` and exactly nine externally
selected anchors: inventory/profile/config/result/supervisor/preservation hashes,
launch commit, arm and chunk. Self-hashes authenticate selected bytes, not the
identity or approval of arbitrary self-signed auditors.

The ignored write-once inventory belongs under
`artifacts/full27_audit_registrations/`, after code/config commits at the exact
launch HEAD. That HEAD stays fixed through terminal; preserve the registration
afterward. Exact31-source/83-runtime/8-data/7-model maps, own auditor/helper pins,
config paths/profile and prior independently audited result/cost authority are
mandatory. Native31 closure remains unchanged because the protocol test is named
`test_independent_full27_audit.py`. Current and preserved bytes are rechecked.

Success requires all nine global updates/180 complete TRAIN rows, physical
parity/training/reference calls and positions, all112 resumed reference gradients,
exact API and paired decoder records,15/19 base proofs and all closed authority
flags. Restored/saved state, same-arm cursor/RNG/source, verified archive bytes,
posted-save/durable-terminal/promotion and latest cumulative costs must agree.
Admission, freshness/resource/deadline limits, owned process identity/Job/lease,
sampler/NVML/hook cleanup and publication ordering are independently checked.
Failed, partial, pending, wrong-source or stale state cannot emit resume authority.

`symbolic_checkpoint.py` inertly interprets bounded ZIP/pickle metadata and
storage bytes, without Torch, pickle execution or model replay. It requires an
explicit protocol header, safe known operations and separately checked inventory
digest, then matches112 FP32 factors,224 Adam moments,112 step scalars and two
RNG storages to the witness. Shape/type/order/finite/nonnegative/step/RNG and
metadata checks reject tampered bytes. Matching RNG bytes does not validate their
encoding through a Torch generator. Unsaved reference tensors and native model
replay are not reconstructed. Training CE values are covered by pinned native
return records; no stored per-row value proof is invented.
