# Staged Phase3 independent terminal auditor

The native `audit_adapter.audit_terminal` is implemented. Its caller must supply
the external terminal/preservation signal, exact source HEAD, inventory file,
profile body, config file and preservation body hashes. These signals do not
establish owner approval or launch authority. No native invocation occurred here.

Before importing the current integrated contract it independently checks every
exact source byte and the clean current Git HEAD, complete current source roster,
cached package module origins, and exact auditor dependency pins. The frozen
registration additionally needs `auditor_dependency_pins` for these six files:
`audit_adapter.py`, `phase_replay.py`, `test_phase_audit.py`, `fixture_support.py`,
`pinned_dependencies/RAM2_auditor_d69810.py`, and its `PRESERVATION.json`.
The ordinary source/runtime/decoder/data/model maps remain exactly those in the
frozen config. The qualified runtime64 digest and exact AST extension remain
mandatory, along with runtime65/decoder17/data5/model7 and the whole64 rows.

The preserved RAM2 source remains SHA256
`d69810dccd11a32595dace73a788c8868efabb2a09f593fd33316e92dcb47442`.
Exactly14 registered textual replacement sites adapt its integrated contract,
new identity/admission and two extra phase files. There are additional explicit
behavioral adaptations: `_NativeReads` supplies strict bounded JSON and regular
streaming file hashing, and the inherited JSONL parser has a finite numeric
facade. They retain valid read/hash values while rejecting aliases, oversize,
truncation, duplicate keys, nonfinite constants and overflow exponents. Every
original decoder/raw/token/logprob/cost/model/resource/ownership/cleanup predicate
remains in the inherited audit body. The complete body comparison test permits
only its registered `contract.base.INFERENCE_AUDIT` substitution.

Independent phase replay does not import or call production phase validators.
It checks the literal complete root/component/API/guard/query/publication tree,
chronology, actual interleaved Journal events, IO count/actual canonical byte
conservation, disk/version/growth/preload observations, exact terminal allocator
and free-memory joins, scope/config/HEAD joins and all closed authority flags.

The loader replay uses the exact pinned source `ASSET_PINS` insertion order,
independently verified seven asset hashes/sizes,310 BF16 shapes and exact2MiB
chunks. After the inherited real model-byte audit succeeds it reads only the
bounded safetensor header and derives first-copy order from independently checked
gapless offsets. Final frozen-base digest order comes from the source-defined
`_base_inventory` return over `_source_shapes` insertion order. A canonical JSON
receipt map is never treated as execution order. All310 copies, first digests,
final digests and682 tensor chunks must match their complete source guard trees.

`fixture_support.native_shaped` and `filesystem` build inert metadata, actual
small fixture files and CPU-only identities. Whole-path controls run the new
source/inventory/terminal/raw/preservation/phase/lease/cleanup/resource/loader
validators. The expensive inherited decoder/model closure is represented by an
explicit CPU stub in this composition control. Other controls compile the exact
adapted original and verify preserved heavy predicates and strict IO facades.
Neither control is a real decoder/model/resource qualification. Fixture finish
always emits `PASS_CPU_FIXTURE_TERMINAL_COMPOSITION_ONLY`, disables native raw
authority and refuses native output writes. Public native admission rejects all
CPU execution scopes. No source, native config, integrated package or launch
gate was edited in this work.

Run `python -I -B run_cpu_validation.py` from this stage. The JSON/text receipts
bind the executed controls and before/after source bytes. The initial staged
three source files are preserved in `pre_terminal_completion_20261005`; failed
whole-path and cleanup-fixture revisions and their reasons remain in their
separate directories. The original preserved auditor was never edited.
