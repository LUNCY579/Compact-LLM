# Optional bounded boundary grammar draft

bounded_boundary_grammar.py is an isolated CPU candidate, not integrated native
policy. It admits an explicit version2 grammar and checks the actual raw emitted
topology before giving a derived ordered plan to the exact pinned historical
event/snapshot replay. The historical consumer's byte/source joins, exact library
effects, event conservation, snapshots, directory identities, cleanup and failure
checks are unchanged. Deriving an order from raw topology grants no native fact.

The grammar has one first framework root, finite required and optional extension
paths, at most one create and exec each, exec after returned create, sequential
IDs and exact LIFO current-stack parents. Every entered pair and every required
pair must complete for success. Original limits remain 2048 boundary entries,
64 depth and 4096 observations. Model scope is false. Unknown, duplicate and
unbalanced records refuse; explicit failure may retain only its reached prefix.

Four CPU controls use actual original raw event/snapshot replay and inert files.
Two sibling extension orders pass with their exact DLL effects. Unknown/repeated
paths, wrong parents, missing required pairs, exec before create and unclosed
boundaries refuse. Missing events and changed expected DLL effects are refused
by the original consumer. These observations are source-shaped CPU fixtures,
not native module notifications or provider efficacy.

This draft leaves per-extension and framework transition expectations entirely
under the original exact policy. The current host's expected effects remain
unresolved in LIBRARY_EXPECTATION_INPUTS001.json. It does not replace them with
an allowed union. No contract, provider, auditor or promoted source was edited;
native gates/permissions/resource/numerical limits are unchanged. Root must
review the registration amendment and integrate explicit source joins before
any runnable proposal can use it.

Original ordered replay source and current contract are retained in
original_ordered_plan_sources001. Final adapter d8e3d06b and test f9b0a4ba pins,
receipt authored_grammar_controls002.json and output GRAMMAR_CONTROLS002.txt are
recorded by SOURCE_PRESERVATION002.json. Native execution remains unqualified.
