`long_native_auditor.py` independently checks actual trace tokens/log probabilities,
EOS versus full32 coverage, declared TRAIN-prefix stress, exact physical prefixes,
call/position caps and per-step bulk maximum/mean errors. It also validates the
persisted fresh200ms factory admission, publication bytes and independent
posted/terminal/promotion cost arithmetic,112 adapter digest observations,
310 base digest observations, three RNG hashes,198 activation sites, resource
chronology and owned Job/lease/cleanup evidence. Typed and altered fixtures reject.
It uses shared schema constants and canonical hashing; production publication
and chain validators are not reused as independent arithmetic authority.

The native `audit()` entrypoint remains hard-disabled. The
[whole terminal-frame CPU composition](LONG_TERMINAL_COMPOSITION_001.md) is
integrated with12 targeted controls. The final native driver still
needs exact external inventory/config/result/supervisor/encoder/preservation/HEAD
joins, complete registration validation, immutable raw/source verification and
cross-process predecessor authority before it can certify an actual scope.
Pure validator returns and native-shaped fixtures cannot issue native PASS,
resume, enrollment, scoring or training authority. No native run was audited.

Digest observations do not save raw RNG states or resident tensor bytes. They
cannot establish encoding/restore or independently rerun model math. Exact byte
pins authenticate externally selected files; self-signed metadata does not
establish independent reviewer authority. Complete encoder/stdlib registration
and current model resource fit remain prerequisites.
