## 1. Run gates on measured resources, not process attribution (item 1)

The original preflight blocked on any `nvidia-smi --query-compute-apps` PID other than its own and on
any "[Insufficient Permissions]" entry. Under WDDM this desktop always lists `dwm.exe` and
`explorer.exe`, so the pilot could never run. `worker.preflight` now blocks on:
- host RAM free < 5 GiB, disk < 6 GiB, measured GPU free < 6 GiB, or a failed GPU query;
- any lease that is not ours (the worker requires the lease to name its supervisor, found among its
  ancestors because the venv `python.exe` is a launcher, plus its token and label);
- a foreign research/model process (python/ollama/llama/vmmem) with ≥ 512 MiB RSS, or one whose
  memory is not visible.

The compute-apps list is recorded as information only. CUDA is capped with
`set_per_process_memory_fraction(0.78)`. Active reserves are GPU 0.5 GiB and host 1.5 GiB, now also
checked per tensor during in-memory arm construction (the H arm's float64 working set).

## 2. In-lane launch (item 2)

The dependency on another lane's containment verifier is removed. That lane (MiMo exact-prefix /
Windows containment) is not modified. Instead:
- **`launch_wmi.py`** starts the supervisor via WMI `Win32_Process.Create`, outside the session's
  process tree. It defaults to a dry run.
- **`supervise.py`**:
  - checks the freeze digest and the bytes it will execute;
  - loads the programme's `gpu_lease.py` only from its pinned bytes;
  - takes the shared lease without waiting, and refuses if the lease is held or a foreign GPU python
    is present;
  - writes the worker pid into the lease, so peers never reclaim it under a live worker;
  - enforces a **600 s hard wall** (the worker's own wall is **540 s**), and kills only its own worker
    tree on overrun;
  - releases its own lease, token-checked, only once the worker has exited. If a kill fails, the lease
    is kept and the receipt says so.
- `SUPERVISOR_START_SECTIONH.json` records the token for a manual own-lease release, should the
  supervisor itself die.

Launch sequence (requires the grant):

    python freeze_sectionh.py freeze          # prints the freeze sha256
    python launch_wmi.py --freeze-sha256 <sha> --grant "<operator grant text>" --launch

## 3. Exact geometry (item 3)

`left_subspace` is now an exact float64 SVD. The original randomized finder missed the exact top-4
subspaces by a 4th principal angle of 22.9° (T) and 22.6° (H), because the spectral gaps are
σ₄/σ₅ = 1.109 and 1.098. That made the operator seed-dependent: 39% from exact, 40–55% across seeds.

The RANDOM control frame is now a sign-corrected Haar QR (seed 20261003). This changes the frame
relative to the original single draw; its rank, spectrum and compute match exactly as before.

`geometry_sectionh.json` records:
- the singular spectra and gaps;
- a rank-1..8 sensitivity table (descriptive; rank 4 is not re-selected);
- the Haar null for ‖K‖₂ (15.6% of random pairs reach the observed 0.1169);
- the legacy randomized geometry's distance from the exact operator (0.393).

## 4. Making a null informative (item 4)

- **Hook liveness, before any TH-hosted unit, on the two DEVELOPMENT mechanics prompts.**
  - IDENTITY must displace exactly 0.
  - For ROTATION, REVERSE and RANDOM, the displaced vectors must match h·B(R−I)ᵀBᵀ computed in float64
    from the registered arrays, element-wise (relative error ≤ 1e-3). Energy must also match and be
    positive. An energy-only check cannot see direction errors: R vs Rᵀ, or a column-reversed union
    basis, displace identical energy, and CPU tests show both are caught only by the vector check.
  - ROTATION must change the logits.
  - Failure → `STOP_MECHANICS_HOOK_LIVENESS`.
- **Teacher-forced sensitivity readout** (no extra generations). TH's greedy tokens are re-scored
  under TH, ROTATION, REVERSE and RANDOM, recording per row:
  - argmax agreement;
  - max |Δlogit|;
  - mean and max KL(TH‖arm);
  - TH's minimum top-2 margin;
  - the target-margin change.
- **Every generation records per-step top-1 margins** and its scored token ids.
- **`UNDETECTABLE_AT_SCREEN`** is registered as distinct from rejection: ROTATION's text equals TH's
  on every screen row.
- **REVERSE** now covers every row.

## 6. The single decision rule (item 6)

This supersedes PREREG lines 106–114, BENCHMARK_MATRIX lines 121–131, REPORT lines 110–111 and
FOLLOWUP_PREREG's continuation rule. It is coded as `benchmark.decide_screen` and applied by the
worker. In execution order, first match wins:

1. `STOP_NATIVE_MECHANICS_PADDING`: padded vs unpadded first 4 tokens differ on a mechanics prompt.
2. `STOP_SCREEN_NO_PARENT_SIGNAL:T|H`: the parent gate fails.
3. `STOP_MECHANICS_HOOK_LIVENESS`: liveness fails.
4. `INCOMPLETE_COVERAGE`: any arm is missing a row it must cover. Every arm covers all 18 rows,
   except PROMPT, which covers the 10 chain rows.
5. `STOP_IDENTITY_CANARY`: IDENTITY text differs from TH on any row.
6. `UNDETECTABLE_AT_SCREEN`: ROTATION text equals TH on every row. This is **not a rejection**: the
   operator moved nothing observable at this scale.
7. `SCREEN_SIGNAL_EXPLORATORY` if all of the following hold, otherwise `NO_SIGNAL`:
   - **S1**: ROTATION's credited J score is above every comparator (BASE, T, H, TH, IDENTITY, RANDOM,
     PROMPT, REVERSE). Beating REVERSE makes the signal sign-specific.
   - **S2**: paired vs TH on J, at least 1 gain and more gains than losses.
   - **S3**: no credited loss vs TH on any answerable J row, so a blanket abstention shift cannot pass.
   - **S4**: no credited loss vs TH on any T, H or K row.

The exact McNemar p (ROTATION vs TH on J) and the floors are reported with every verdict. **No outcome
is confirmation.** A NO_SIGNAL rejects only this exact-SVD layer-14 rank-4 construction at η = 0.1, on
this screen.

## 8. Benchmark matrix status (erratum)

These families are relabelled **"diagnostic rows exist, unqualified"**, not "Available": instruction
following, math, answerability, state tracking, unfamiliar rules, contradiction detection and skill

before a Wilson 95% damage bound can fall below 10%. No family claim follows from this screen.

## 9. Limits stated before any data

- The prior for a geometry-only lever is low: orthogonality was not the lever, and a norm-matched
  random update was inert. ‖R−I‖₂ = 0.0117, and the T–H overlap sits at the Haar null.
- Exclusion against protected banks rests on construction, not on opening them. That construction is:
  new surface forms, the legacy pool cue-word scan, and T-row operand collision checks against exposed
  banks. C_FRESH, T_BANK_V5, H_FRESH and HSKILL_CONFIRM_V2 remain unopened; TRISKILL Stage B stays sealed.

  zero multiplier, so a model that only knows "0·x resets" scores 5/8, not 8/8.
- One draw each of the parents, the random frame and the screen rows. A screen signal would justify a
  separately registered, powered study, never a capability claim.
