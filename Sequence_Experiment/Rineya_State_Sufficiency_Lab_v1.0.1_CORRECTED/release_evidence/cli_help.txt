usage: rineya-state-lab [-h] [--version]
                        {data,train,evaluate,compare,experiment,doctor,smoke-test} ...

Train and evaluate full-context versus compact-state reasoning adapters.

positional arguments:
  {data,train,evaluate,compare,experiment,doctor,smoke-test}
    data                Prepare and validate the paired dataset
    train               Train one LoRA/QLoRA adapter
    evaluate            Run one configured evaluation matrix
    compare             Run paired statistical comparison by problem ID
    experiment          Run the complete staged experiment
    doctor              Inspect Python, CUDA, dependencies, model, and dataset
    smoke-test          Run a no-model reference evaluation and comparison

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
