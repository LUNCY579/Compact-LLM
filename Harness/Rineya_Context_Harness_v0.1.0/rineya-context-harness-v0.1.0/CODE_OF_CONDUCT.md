# Contributor Code of Conduct

## Our commitment

We are committed to a respectful, technically rigorous, and welcoming project environment. Participants should be able to question assumptions, report failures, and disagree about architecture without personal hostility.

## Expected behavior

- Be respectful and specific.
- Critique designs, evidence, and code rather than people.
- State uncertainty and limitations honestly.
- Credit prior work and contributors.
- Protect private data and unpublished evaluation material.
- Preserve negative results when they improve scientific understanding.
- Help newcomers understand project contracts and safety boundaries.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Publishing private information without permission.
- Misrepresenting benchmark results, review status, or security guarantees.
- Concealing known data leakage, evaluation contamination, or destructive behavior.
- Deliberately weakening safeguards without disclosure and review.

## Enforcement

Repository maintainers may edit, reject, revert, lock, or remove contributions and participation that violate this policy. Serious concerns should be reported privately to the project owner or designated conduct contact when one is published.
