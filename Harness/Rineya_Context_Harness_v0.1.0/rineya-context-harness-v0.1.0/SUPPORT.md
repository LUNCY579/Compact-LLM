# Support

Rineya Context Harness v0.1 is research infrastructure rather than a supported hosted service.

For a reproducible problem report, include:

- harness version or commit;
- Python version and operating system;
- redacted configuration;
- exact command;
- smallest fixture that reproduces the issue;
- relevant trace and state-event excerpts with secrets removed;
- expected versus observed result;
- whether the problem occurs with the deterministic fixture backend.

Do not attach private conversations, API keys, model weights, sealed evaluation data, or unredacted runtime databases.
