# Examples

All examples are network-free and deterministic.

```bash
python examples/restaurant_route.py
python examples/tower_of_hanoi.py
python examples/fixture_research.py
```

- `restaurant_route.py` demonstrates update + supersede + explicit eviction.
- `tower_of_hanoi.py` demonstrates pinned rules plus replaceable current board state.
- `fixture_research.py` demonstrates search, evidence persistence, reconstruction, raw-evidence eviction, context rebuild, answerability, and cited answer.
