# Release Gates

## Technical validity gate

All required:

- repository validation passes;
- tests and coverage pass;
- schemas reproduce;
- no corrupted ZIP member;
- configuration and model revisions are recorded;
- no sealed-evaluation contamination;
- traces and reports are readable;
- rollback works.

## Relative opportunity gate

Compare RSF to the declared baseline using proportional benefit versus proportional quality loss. Do not hide category regressions behind one aggregate score. Report at least:

- balanced quality weighting;
- logic/evidence-oriented weighting;
- conversational-permissive weighting;
- Pareto frontier;
- deletion regret and invariant loss separately.

## Human gate

Human review remains required for:

- safety boundaries;
- empathy;
- roleplay consistency;
- naturalness;
- citation presentation;
- privacy/reset behavior;
- public claims.
