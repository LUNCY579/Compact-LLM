## Number-reporting rule

Every paper-facing numeric table must be generated from or checked against a
machine artifact above. A manually copied number must include its evidence ID,
dataset role, N, source hash, and generation script in the table note or
appendix provenance table. Numbers without a resolvable artifact are
placeholders, not results.
