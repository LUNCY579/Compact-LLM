1. Task: typed milestone planning. A plan is a finite trace of distinct action IDs accepted by an AND/OR prerequisite net. Each action has an integer guard g, consumption c, production p, duration d, monetary charge k, operator type τ, and terminal-goal effects. Start with r=(r0,r1); executing a requires r≥g and r-c≥0, applies its learned transition, and must leave r in [0,12]^2. For selected pairs, every active precedence edge must be respected. No unselected action creates an obligation. Total duration must satisfy the query deadline; an accepted trace must complete at least one query-permitted terminal goal. No hidden parallelism, reset, repeated action, or implicit resource replenishment exists.

Candidate operator hypotheses are declared background laws; their actual identities are variable evidence. Type T has mode b?{0,1} and transfers b units from r0 to r1 after the action's declared c,p update; type B burns b units of r1 after that update. A transition with insufficient stock is illegal. Each operator also updates a marker z to z XOR b. A calibration episode exposes its input marker and observed output marker as separate linked records, with resource components unobserved. Thus b=input XOR output, requiring both records; real plan calls must use resource states different from calibration states. The transfer/burn distinction must have a reached resource consequence, not merely a marker difference.

Among feasible traces maximize query utility, then minimize elapsed duration, then monetary cost; lexicographic action-ID order is solely serialization tie-breaking. Define D=(PLAN/INFEASIBLE, completed-goal IDs, selected action/alternative IDs), excluding trace order, duration, cost, and ending resource. Define Q=(D, ordered trace, utility, elapsed duration, cost, ending resource). No feasible trace gives canonical INFEASIBLE. Counterfactual decision gates require a unique optimal D before lexicographic tie-breaking; order-only and tie-break-only changes fail.
