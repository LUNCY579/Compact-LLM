# Phase 10 file responsibilities

| File | Responsibility |
|---|---|
| `run_phase_10.ps1` | Ordered orchestration, resume, recovery, challenger, final gate. |
| `finalize_phase_9_selection.py` | Materialize any exact legacy or hybrid Phase 9 candidate key, enforce research-control acknowledgement, and write the Phase 9 reference. |
| `resolve_phase_9_student.py` | Resolve that immutable handoff. |
| `profile_student_structure.py` | Collect residual, MLP-channel, and attention-head contribution proxies. |
| `phase10_common.py` | Candidate parsing and real tensor-slicing primitives. |
| `create_structural_candidate.py` | Build, save, fresh-reload, and manifest one physically smaller candidate. |
| `select_recovery_candidates.py` | Select a bounded recovery search set; does not promote. |
| `check_phase_10_gate.py` | Shared relative-opportunity registry/report/pending gate. |
| `finalize_phase_10_selection.py` | Merge an approved adapter if needed, materialize checkpoint, write Phase 10 reference and rollback. |
| `resolve_phase_10_student.py` | Resolve the approved Phase 10 checkpoint for Phase 11. |
