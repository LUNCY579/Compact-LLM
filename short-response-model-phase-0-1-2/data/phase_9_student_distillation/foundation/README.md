# Phase 9 synthetic behavior foundation

This versioned pack contains fictional product facts, controlled unsupported questions, retrieval-injection cases, reusable procedures, and concise social replies. It is safe to use as supplemental **training-only** data because every answer is authored from the supplied synthetic evidence. It must never be used as a substitute for held-out real-domain evaluation or broad language pretraining.

The pack is designed to teach the evidence prompt format, supported extraction, exact abstention, procedure use, injection resistance, concise social behavior, and EOS behavior.
