# v2.2 Multi-Domain Capability Curriculum

- Canonical: **40,500** rows
- Domains: **27**
- Archetypes: **15**
- TRAIN / DEV / TEST: **32,400 / 4,050 / 4,050**

All gold answers are computed from prompt-contained information. The assistant target contains only the concise final answer. High-stakes domains use fictional rules and conservative uncertainty examples; this dataset is for reasoning behavior, not factual reference memorization.

Specialist views are derived from TRAIN only and never consume DEV/TEST rows.
