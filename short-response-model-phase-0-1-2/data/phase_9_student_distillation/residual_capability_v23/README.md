# v2.3 Preservation-Constrained Residual Capability Data

This directory contains the two fresh v2.3 data programs:

- `direct_reasoning/`: 24,300 prompt-contained cases with split-disjoint surface representations and explicit answerable-vs-abstention measurement.
- `procedural_rag/`: 7,200 fresh Real-RAG procedure cases with exact audit/record binding, missing-input cases, structured conflicts, and a fresh sealed split.

The v2.2 sealed TEST is considered consumed. v2.3 mining/training/selection may use only `discovery`, `dev`, and `ood_dev` according to the runner contract. `fresh_sealed` is touched only after a single v2.3 DEV/OOD winner is frozen.
